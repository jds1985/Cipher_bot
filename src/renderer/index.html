Cipher Bot

Cipher Bot is locked

There is no recovery: Cipher Bot can't reset a forgotten passphrase. If you forget it, quit Cipher Bot and delete the file lock.json in Cipher Bot's user data folder. That removes the lock and keeps your chats. The lock does not encrypt anything.

Settings

Lock

Cipher Bot locks each time it starts and as soon as its window is closed to the tray, and asks for this passphrase before showing anything again. The passphrase never leaves this computer; only a salted hash is kept, in lock.json. The lock does not encrypt your chats, and there is no recovery if you forget the passphrase.

Backup

Saves a copy of all your Cipher bots, chats, rooms, routines and settings to a file you choose on this computer. The backup is not encrypted: anyone who can open the file can read your chats. It does not include the lock.

Scheduled backup

Saves a backup on its own, daily or weekly, into a folder you choose on this computer. Old backups are kept; nothing is sent anywhere. Backups never include the lock.

Shared folder

One folder every Cipher bot can read (never write), separate from each bot's own folder. A bot reads it only when its Files switch is on.

None

Restore

Replaces all current Cipher bots and chats with a backup file you choose. Cipher Bot first keeps a copy of the current database next to it, then restarts. The lock on this computer stays as it is, and Online is turned off.
