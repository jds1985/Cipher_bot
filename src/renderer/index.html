Cipher is locked

There is no recovery: Cipher can't reset a forgotten passphrase. If you forget it, quit Cipher and delete the file lock.json in Cipher's user data folder. That removes the lock and keeps your chats. The lock does not encrypt anything.

Settings

Lock

Cipher asks for this passphrase each time it starts and each time its window is shown again (for example, from the tray). The passphrase never leaves this computer; only a salted hash is kept, in lock.json. The lock does not encrypt your chats, and there is no recovery if you forget the passphrase.

Backup

Saves a copy of all your Cipher bots, chats, rooms, routines and settings to a file you choose on this computer. The backup is not encrypted: anyone who can open the file can read your chats. It does not include the lock.

Restore

Replaces all current Cipher bots and chats with a backup file you choose. Cipher first keeps a copy of the current database next to it, then restarts. The lock on this computer stays as it is, and Online is turned off.

Phone link

Open your chats in a phone browser on the same Wi‑Fi. The model stays on this computer. Pairing codes expire after about 12 minutes; after pairing, the phone uses a session token.
